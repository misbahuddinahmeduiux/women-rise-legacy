INSTALLATION
1. Back up the current working Phase 5 folder.
2. Extract this package into a new folder.
3. Copy client/.env and server/.env from the working Phase 5 folder.
4. Run npm install from the project root if node_modules is not present.
5. Run: npm run validate:phase6
6. Run: npm run typecheck
7. Run: npm run build
8. In Supabase SQL Editor run: supabase/PHASE-6-HOMEPAGE-UI.sql
9. Then run: supabase/PHASE-6-VERIFY.sql
10. Start the application and review the homepage on desktop and mobile.
