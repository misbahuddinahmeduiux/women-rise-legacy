# Women Rise Legacy — Phase 2

A combined Women Rise Legacy Network and Foundation platform built with React, Express, and Supabase.

Start with `README-FIRST.txt`.

## Main commands

- `1-install-packages.bat` — install dependencies and create missing `.env` files
- `2-start-project.bat` — start API and website
- `3-build-project.bat` — production build
- `4-check-project.bat` — TypeScript checks
- `5-open-phase-2-sql.bat` — open the Phase 2 migration file
- `6-open-phase-2-verify.bat` — open the read-only database verification file

## Database

Run `supabase/PHASE-2-SETUP-ALL.sql` in the existing Phase 1 Supabase project.
